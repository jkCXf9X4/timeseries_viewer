# Interaction summary

The core interaction runs from opening sources to saving the workspace.

- **Open:** open one or more sources.
- **Browse:** browse source trees in the left sidebar.
- **Select:** check variables to add them to the active tab.
- **Focus:** click a window or tab to change the active plot.
- **Edit:** edit the active plot in the right sidebar.
- **Derive:** add derived series from the active tab when needed.
- **Save:** save the workspace as a project file.
