# Center workspace behavior

The center workspace is the plot surface and analysis area.

- **Windows:** more than one analysis window may be visible at once; a window is a top-level analysis context inside the application with its own tab set.
- **Activation:** clicking a window makes it the active analysis window.
- **Tabs:** each tab contains exactly one plot, belongs to one analysis window only, and clicking a tab makes it the active plot.
- **Tab titles:** tab titles are editable from the plot inspector.
- **Active tab:** the active tab determines which plot the side-panel edits affect.
- **Plot surface:** the plot surface shows the plot only, with plot settings edited elsewhere, and raw and derived series may be overlaid in the same plot.
