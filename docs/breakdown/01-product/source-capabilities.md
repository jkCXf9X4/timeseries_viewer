# Source and variable capabilities

The viewer opens and inspects multiple source files in one session and finds variables through a nested tree.

- **Multi-source:** open and inspect multiple source files in one session.
- **Tree browse:** find variables through a nested tree built from dotted names.
- **Parameter menu:** use a menu or panel to choose which parameters are displayed and which open source provides them.
- **Time axis:** select time axis and value columns where necessary.
