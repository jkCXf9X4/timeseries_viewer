# Source and selection requirements

The viewer must make source browsing and variable selection visual and explicit.

- **Browser:** the source browser makes file and variable selection visual and explicit.
- **Hierarchy:** the app supports nested variable names that use `.` as a hierarchy separator.
- **Menu:** the app exposes an explicit parameter-selection menu or panel that maps parameters to open files or databases.
