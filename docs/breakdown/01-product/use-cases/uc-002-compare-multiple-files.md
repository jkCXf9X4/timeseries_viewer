# Compare multiple files in one plot

"Let me plot the same signal from several files or databases together and compare them in one view."

- **Actor:** an analyst who has the same measurement stored in separate runs, files, or databases.
- **Goal:** inspect the signals together without a separate plot per source.
- **Request:** "show this signal from these sources in the same plot so I can compare them."
- **Behavior:** multiple sources stay open at once, and a plot view contains series from different sources.
- **Outcome:** the comparison is visible in one plot with labels clear enough to tell similar-named series apart.
