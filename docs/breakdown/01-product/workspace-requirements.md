# Workspace and persistence requirements

The workspace must support a multi-window layout, understandable time selection, and saved-view restore.

- **Layout:** the workspace supports multiple simultaneous windows, multiple tabs per window, and exactly one plot per tab.
- **Time selection:** time selection is understandable and overridable by the user.
- **Comparison:** derived comparisons are usable in the same plot workspace as raw series.
- **Restore:** saved views restore the essential state of the analysis session.
