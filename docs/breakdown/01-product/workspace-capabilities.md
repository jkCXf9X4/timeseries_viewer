# Workspace and plot capabilities

The viewer supports a multi-window, multi-tab plotting workspace with derived series and saved state.

- **Workspace:** view multiple analysis windows simultaneously, with multiple tabs per window and one plot per tab.
- **Overlay:** overlay multiple series in a single plot.
- **Derived series:** create derived series from expressions.
- **Persistence:** persist workspace state and restore it later.
