# Support constraints

The product behaves as a local desktop utility with clear user-owned data boundaries.

- **No backend:** no backend service is required.
- **User-owned files:** source files remain under user control.
- **Portability:** project files are portable across machines when paths are resolvable.
- **Clear failure:** the application fails clearly when a file cannot be opened, parsed, or refreshed.
- **Live mode:** live mode remains understandable even when a source changes unexpectedly.
