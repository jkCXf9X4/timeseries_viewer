# Operational risks

Operation carries three main risks.

- **Memory:** large files may need stronger memory guidance later.
- **Path portability:** path portability can fail when project files move across environments with different directory layouts.
- **Packaging:** the low-dependency approach may still require packaging attention for Linux desktop distributions.
