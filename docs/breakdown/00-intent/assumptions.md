# Intent assumptions

The viewer is usable without a backend service, and CSV and SQLite cover the first release.

- **Backend:** the user wants a tool usable without a backend service.
- **Sources:** CSV and SQLite are sufficient to cover the first-release use case.
- **Priorities:** the product optimizes for discoverability and comparison, not for advanced data-science automation.
