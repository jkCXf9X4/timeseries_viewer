# Intent constraints

The viewer is a Linux-first, low-dependency, self-contained desktop application centered on local files.

- **Platform:** Linux is the primary supported platform.
- **Footprint:** the application stays low-dependency and self-contained.
- **Data:** the workflow centers on local files rather than remote services.
- **Scope:** the first version stays practical instead of overgeneralizing to every data source or expression feature.
