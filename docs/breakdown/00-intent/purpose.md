# Why the viewer exists

The viewer gives engineers a simple, standalone way to inspect and compare time-series data on Linux without a server, cloud workspace, or heavy operating environment.

- **Workflow:** opening local data files, finding a variable quickly, comparing signals in one view, testing derived relationships like `a - b`, and saving the analysis state for reuse.
- **Friction:** each workflow step should feel immediate and local rather than routed through a backend.
- **Discoverability:** finding the right variable quickly is a core reason the tool exists.
- **Comparison:** testing derived relationships such as `a - b` is a primary workflow.
- **Reuse:** saving the current analysis state for later reuse is expected.
