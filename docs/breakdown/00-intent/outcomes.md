# Desired outcomes

The viewer should be a standalone desktop tool that feels immediate and local.

- **Standalone:** a desktop tool that feels immediate and local, with no backend dependency.
- **One place:** source discovery, plotting, comparison, and saved views stay in one workflow.
- **Scale:** the tool works well for medium-sized datasets and common engineering logs.
- **Boundary:** the first version stays practical rather than overgeneralizing to every data source or expression feature.
