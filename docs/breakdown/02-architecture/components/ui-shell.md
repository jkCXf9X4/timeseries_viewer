# UI shell component

The UI shell provides the multi-window workspace and its controls.

- **Workspace:** provides the multi-window workspace.
- **Browser:** provides the source browser.
- **Parameter menu:** provides the parameter-selection menu.
- **Plot tabs:** provides plot tabs.
- **Expression editor:** provides the expression editor.
- **Project actions:** provides project actions.
- **Foundation:** the UI and plotting foundation is Dear ImGui, ImPlot, and GLFW.
- **Layout contract:** the detailed layout contract is in the UI description (`INFO-010`).
