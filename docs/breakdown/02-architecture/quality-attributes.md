# Quality attributes

The architecture targets five quality attributes.

- **Footprint:** low dependency footprint.
- **Platform:** predictable behavior on Linux desktop environments.
- **Responsiveness:** responsive interaction for medium-sized datasets.
- **Recovery:** clear recovery when data changes or a variable becomes unavailable.
- **Restoration:** traceable state restoration for analysis sessions.
