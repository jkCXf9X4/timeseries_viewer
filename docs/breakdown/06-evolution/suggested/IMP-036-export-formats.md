# More export formats

- **Question:** how does a user take plotted results out of the application?
- **Evidence:** the application has no export path beyond saving project files (`INFO-016`).
- **Change:** additional export formats are added for plots and project state.
- **Risk:** export must not change the underlying model or project schema.
- **Acceptance:** a user exports a plot or project state in a chosen format and the exported artifact matches the current view.
