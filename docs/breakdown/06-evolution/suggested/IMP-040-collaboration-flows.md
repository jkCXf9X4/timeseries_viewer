# Collaboration and shared review flows

- **Question:** when would the viewer support collaborative or shared review flows?
- **Evidence:** the product is a standalone local tool with networked collaboration explicitly out of scope for V1 (`INFO-007`).
- **Change:** collaboration or shared review flows are added only if the product direction changes materially toward shared analysis.
- **Risk:** collaboration contradicts the local, no-backend intent and requires server or sync infrastructure.
- **Acceptance:** a shared-review flow exists only after a product-direction decision makes it in scope.
