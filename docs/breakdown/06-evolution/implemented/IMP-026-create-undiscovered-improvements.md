# Create undiscovered-improvements placeholder

- **Question:** where do area-scan notes record that an exploration produced no concrete improvement candidate?
- **Evidence:** the review checklist named an undiscovered-improvements file that did not exist, so non-candidate exploration had no designated home.
- **Change:** a file documents its purpose and an empty-state note, cross-referenced from the improvement index so it is not orphaned.
- **Risk:** the file is not populated with actual improvement entries.
- **Acceptance:** the file exists with a clear purpose statement and an empty-state note, and it is referenced from at least one index file.
