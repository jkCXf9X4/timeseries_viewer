# Expand changelog

- **Question:** how does the changelog record what was implemented between versions?
- **Evidence:** the changelog is a single unreleased section listing initial features with none of the found improvements mentioned.
- **Change:** changelog entries summarize the implemented improvements under version headings, each referencing its improvement record.
- **Risk:** existing unreleased content stays intact and other docs are untouched.
- **Acceptance:** the changelog contains entries for the implemented improvements with brief descriptions, consistent formatting, and no removed existing content.
