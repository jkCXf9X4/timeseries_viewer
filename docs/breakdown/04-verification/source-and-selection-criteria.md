# Source and selection acceptance criteria

The viewer is accepted when source handling and selection meet these checks.

- **Source browsing:** the source browser exposes CSV and SQLite content consistently.
- **Binding visibility:** the parameter-selection UI keeps file and database bindings explicit.
- **Selection:** the variable browser supports both add and remove through tickbox selection.
- **Side panels:** the side panels remain fixed to their sides while allowing width adjustment.
- **Persistence:** the same source state can be saved and restored from a project file.
