# Traceability targets

Verification targets trace back to their owning layers by ID.

- **Capabilities:** product capabilities are traced from the product leaves (`CP-001`, `CP-002`).
- **Architecture:** architecture dependencies are traced from the architecture leaves (`INFO-017`, `INFO-024`).
- **Implementation:** implementation hooks are traced from the implementation leaves (`INFO-028`, `INFO-029`).
