# Source and binding integration coverage

Integration tests exercise source handling and binding.

- **Multi-source:** open multiple sources in one session.
- **Selection:** select and deselect variables from nested names using tickboxes.
- **Binding:** select parameters through a menu or panel and verify the chosen source binding is reflected in the displayed plot.
- **Overlay:** overlay multiple raw series in one view.
- **Derived:** create a derived `a - b` series and verify alignment.
