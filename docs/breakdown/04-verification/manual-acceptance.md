# Manual acceptance

Manual checks cover the user-visible workflow on Linux.

- **Launch:** the app launches cleanly on Linux.
- **Sources:** the user can browse multiple sources without a backend service.
- **Parameter menu:** the user can choose parameters through an explicit menu or panel rather than implicit hidden binding.
- **Selection:** the user can add or remove variables from the plot by ticking and clearing checkboxes in the variable browser.
- **Windows:** the user can keep multiple windows open simultaneously, with each tab showing one plot and its own selection state.
- **Side panels:** the user can keep the parameter browser fixed on the left and the plot inspector fixed on the right, with both panels following the active plot.
- **Workflow:** the user can create, compare, and save views without leaving the application.
